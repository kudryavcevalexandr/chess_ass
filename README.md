# Screen Recorder

Нативное Android-приложение на Kotlin для записи изображения с экрана в MP4 без
микрофона и системного звука.

## Как пользоваться

1. Нажмите **«Выбрать папку и начать»** и выберите папку в системном диалоге.
2. Подтвердите системный запрос Android на захват экрана.
3. Сверните приложение: запись продолжит работать как foreground service.
4. Остановите запись кнопкой в приложении или действием **«Остановить»** в
   постоянном уведомлении. Файл `screen_YYYY-MM-DD_HH-mm-ss.mp4` появится в
   выбранной папке.

Android из соображений приватности всегда показывает системное подтверждение
перед каждой сессией захвата экрана. Во время записи также отображается
постоянное уведомление — скрытая запись средствами публичного Android API
невозможна.

## Сборка

Требуются JDK 17, Android SDK 35 и Gradle 8.10.2 или новее. Gradle Wrapper
намеренно не хранится в репозитории, потому что его загрузчик
`gradle-wrapper.jar` является бинарным файлом. Сборка выполняется установленным
в системе Gradle:

```bash
gradle assembleDebug
```

APK будет создан в `app/build/outputs/apk/debug/app-debug.apk`.
